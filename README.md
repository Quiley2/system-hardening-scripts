# System Hardening & Automation Scripts

Raccolta di script in PowerShell e Bash sviluppati per l'automazione delle attività sistemistiche, il controllo dello stato dei server e l'applicazione di baseline di sicurezza (hardening) su infrastrutture Windows Server e Linux.

## Contenuto della Repository
- `windows-baseline-check.ps1`: Script di verifica dei parametri di sicurezza di base su Active Directory e policy locali.
- `linux-audit-log.sh`: Script di estrazione e analisi rapida dei log di autenticazione per l'individuazione di tentativi di accesso anomali.

## Obiettivo
Garantire la conformità agli standard di sicurezza aziendale, ridurre la superficie d'attacco e automatizzare il monitoraggio preventivo della continuità operativa.
